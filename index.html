Arduino sketch

Simple, readable logic

The Arduino reads an analog sensor value and uses threshold ranges to select the weather condition and LED output.

// Smart Rain Detection System int rainSensor = A0; int greenLED = 8; int yellowLED = 9; int redLED = 10; void setup() { pinMode(greenLED, OUTPUT); pinMode(yellowLED, OUTPUT); pinMode(redLED, OUTPUT); } void loop() { int rainValue = analogRead(rainSensor); digitalWrite(greenLED, LOW); digitalWrite(yellowLED, LOW); digitalWrite(redLED, LOW); if (rainValue > 800) { digitalWrite(greenLED, HIGH); } else if (rainValue > 400) { digitalWrite(yellowLED, HIGH); } else { digitalWrite(redLED, HIGH); } delay(500); }
